# Hibernate Projects 🚀

Welcome to my Hibernate learning repository.

This repository contains my Java Hibernate and JPA practice projects, covering
Hibernate fundamentals, CRUD operations, JPA, and entity relationships.

## 🛠️ Technologies Used

- Java
- Hibernate ORM
- JPA
- Maven
- MySQL
- JDBC
- Eclipse IDE

## 📚 Projects

### 01 - Hibernate Basics

Basic Hibernate concepts including:

- Hibernate configuration
- SessionFactory
- Session
- Entity mapping
- HBM XML mapping
- Saving objects into MySQL

### 02 - Hibernate CRUD

CRUD operations using Hibernate:

- Insert
- Find
- Update
- Delete
- Hibernate configuration
- MySQL database connectivity

### 03 - Hibernate JPA

JPA-based persistence concepts:

- Entity
- EntityManager
- Persistence
- JPA annotations
- Database operations

### 04 - OneToOne Uni

Unidirectional One-to-One relationship using Hibernate/JPA.

Topics include:

- One-to-One mapping
- Entity relationships
- Foreign keys
- Relationship mapping
